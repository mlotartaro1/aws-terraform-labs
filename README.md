\# AWS Terraform Labs



Laboratorios prácticos de AWS con Terraform, como preparación para la certificación AWS Solutions Architect – Associate (SAA-C03).



| Lab | Contenido |

|---|---|

| lab01-vpc | VPC, subred, Internet Gateway y route table |

| lab02-web | Servidor web en EC2 con Security Group y user\_data |

| lab03-ha | Alta disponibilidad: ALB + Auto Scaling en 2 AZs |

| lab04-private | Subredes privadas, NAT Gateway, SSM y HTTPS en el ALB |
